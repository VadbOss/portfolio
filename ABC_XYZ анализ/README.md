## 📈 Общая структура портфеля

По данным выборки (20 позиций) и экстраполяции на весь ассортимент:

| Показатель | Значение |
| :--- | :--- |
| Всего SKU | **~6 500** |
| Товары группы **AX** (приоритет №1) | **~5%** (товары с A по объему и X по стабильности) |
| Товары группы **AZ** (высокие продажи, нестабильные) | **~15%** (требуют повышенного внимания) |
| Товары группы **CZ** (на вывод) | **~20-25%** (C по объему + C по прибыли) |
| "Спящие" товары (C по всем метрикам) | **~15%** |

**Ключевой вывод:**  
✅ **Сильная сторона** — большая часть ассортимента относится к группам `B` и `C`, что говорит о **широком охвате** ниш.  
⚠️ **Зона роста** — значительная доля товаров категории `C` (низкая выручка/прибыль) **замораживает капитал** и требует ребалансировки.

## 🧮 Финансовые метрики (на основе экстраполяции)

| Метрика | Значение |
| :--- | :--- |
| **Доля товаров C по прибыли** | ~30-40% ассортимента — **это зона убытков или низкой маржи** |
| **Замороженный капитал в C-группах** | Оценивается в **20-30% от общей стоимости запасов** |
| **Риск дефицита** | **ВЫСОКИЙ** по группе AZ (хиты с нестабильным спросом) |

> 💡 *Высвобождение капитала из C-групп позволит увеличить закупку перспективных позиций (A и B) и повысить оборачиваемость на 15-20%.*
