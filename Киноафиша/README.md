# 🎬 КИНОАФИША — дашборд для анализа фильмов

## Обзор
Дашборд **КИНОАФИША** предназначен для визуального анализа базы данных фильмов, собранной с сайта **Киноафиша**. Он позволяет быстро оценить количество фильмов, их рейтинги, распределение по странам и жанрам, а также динамику выхода фильмов по годам.

---

## 📦 Источник данных
- **Сайт:** [Киноафиша](https://[www.kinoafisha.info](https://www.kinoafisha.info/)
- **Способ сбора:** парсинг данных (веб-скрапинг) с карточек фильмов.
- **Собранные поля:**  
  - Название фильма  
  - Год выпуска  
  - Жанр(ы)  
  - Страна производства  
  - Рейтинг (оценка зрителей / кинокритиков)

## 🧭 Структура и элементы управления

### Верхняя панель (слева)
- **Фильтр-бегунок «Год»** — диапазон от **1964** до **2023**.  
  Позволяет выбрать конкретный год или временной промежуток для анализа.

- **Фильтр-выпадающий список «Жанр»** — выбор одного или нескольких жанров кинофильмов.  
  Динамически обновляет все визуализации на дашборде.

### Верхняя панель (справа)
Два ключевых показателя (карточки с одним значением):
- **Количество фильмов всего** — общее число фильмов, попавших в выборку с учётом применённых фильтров.
- **Средний рейтинг фильмов** — усреднённая оценка всех отобранных фильмов (по шкале сайта Киноафиша).

## 📊 Графики и визуализации (нижняя часть)

### 1. Количество фильмов по странам
- **Тип:** горизонтальная столбчатая диаграмма.
- **Описание:** показывает, какие страны производят больше всего фильмов, с сортировкой по убыванию.

### 2. Таблица фильмов
- **Поля:**  
  - Название фильма  
  - Год выпуска  
  - Средний рейтинг  
- **Назначение:** детальный список фильмов, соответствующий текущим фильтрам. Позволяет быстро найти конкретные картины.

### 3. Динамика количества фильмов по годам
- **Тип:** линейный график.
- **Описание:** отображает, как менялось общее число выпущенных фильмов за каждый год в выбранном диапазоне. Помогает выявить тренды и пиковые годы.

### 4. Количество фильмов по жанрам
- **Тип:** столбчатая диаграмма (вертикальная).
- **Описание:** распределение фильмов по жанровым категориям. Позволяет понять, какие жанры наиболее популярны в выборке.

## 🔄 Взаимодействие
Все фильтры (год, жанр) работают согласованно — изменение любого параметра мгновенно обновляет все графики и карточки показателей. Это обеспечивает удобный многомерный анализ данных.

---

## 📐 Созданные меры (DAX)

| Мера | Формула | Назначение | Где используется |
|------|---------|------------|------------------|
| **Количество фильмов** | `DISTINCTCOUNT('Киноафиша'[Название фильма])` | Подсчитывает уникальные названия фильмов в выборке с учётом применённых фильтров | Карточка «Количество фильмов всего» |
| **Средний рейтинг** | `AVERAGE('Киноафиша'[Рейтинг])` | Вычисляет среднюю оценку фильмов по текущему фильтрованному набору данных | Карточка «Средний рейтинг фильмов» |
| **Ср рейтинг для России** | `CALCULATE(AVERAGE('Киноафиша'[Рейтинг]), 'Киноафиша'[Страна] = "Россия")` | Рассчитывает средний рейтинг только для фильмов, произведённых в России | Дополнительный анализ (при необходимости) |
| **Ср рейтинг от 8.65** | `IF('Киноафиша'[Средний рейтинг] > 8.65, 'Киноафиша'[Средний рейтинг], BLANK())` | Отображает средний рейтинг только для фильмов с оценкой выше 8.65; для остальных возвращает пустое значение | Используется для выделения высокорейтинговых фильмов в таблице |
