## 📌 ТОП-5 мер для повышения retention

| № | Мера | Ожидаемый эффект |
| :--- | :--- | :--- |
| 1 | **Внедрить триггер на 3-й неделе** (скидка/бонус/персонализация) | +10-15% retention на Week 3-4 |
| 2 | **Reactivation-кампания на 5-й неделе** (для "уходящих") | Возврат 5-10% пользователей |
| 3 | **Программа лояльности для активных на 8+ неделе** | Увеличение LTV на 20-30% |
| 4 | **Анализ качества трафика по когортам** | Снижение CAC на 15-20% |
| 5 | **A/B-тестирование коммуникаций** (какие офферы работают лучше) | Оптимизация маркетингового бюджета |
