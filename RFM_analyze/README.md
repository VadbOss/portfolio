# RFM-анализ клиентской базы аптечной сети

* **Стек:** PostgreSQL, Metabase
* **Исходные данные:** БД `Apteka`, таблица `bonuscheques`
* **Период анализа:** 12-07-2021 — 09-06-2022

---

## Цель проекта
* Классифицировать клиентов на основе RFM-анализа.
* Сформировать рекомендации по маркетинговым активностям для каждой группы пользователей.

---

## Данные
* **Источник:** Данные по транзакциям бонусных карт.
* **Очистка данных:** Включены только онлайн-транзакции (13-символьные карты).

### Итоговая выборка после очистки:
* **Клиенты:** 5 926 из 9 394
* **Транзакции:** 21 075 (по 13-символьным картам)
* **Аптеки:** 11 торговых точек
* **Выручка:** 19,2 млн руб.
